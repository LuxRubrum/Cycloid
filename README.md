# Cycloid

Программа для расчёта и визуализации траектории точки, закреплённой на расстоянии от оси колеса, которое катится без проскальзывания.

## Общее описание

Приложение моделирует движение точки, расположенной на некотором расстоянии `rDot` от оси вращения колеса радиуса `rWheel`. Колесо перемещается в пространстве с заданной линейной скоростью `vLinWheel`. В начальный момент времени точка находится в самом нижнем положении.

**Результат работы:**
- график траектории точки в координатах X–Y;
- отметки положения точки в моменты времени t = 0.4 с и t = 0.8 с;
- векторы направления движения и числовые значения линейной скорости точки в этих моментах;
- подписи, легенда и автомасштабирование области построения.

**Входные параметры:**
| Параметр | Описание |
|---|---|
| `vLinWheel` | Линейная скорость перемещения колеса (может быть отрицательной, нулевой, положительной) |
| `rWheel` | Радиус колеса (строго положительный) |
| `rDot` | Расстояние от точки до оси вращения (строго положительное) |
| `dt` | Шаг времени дискретизации (строго положительный) |

## Архитектура

Проект построен по шаблону **MVVM** и разделён на две логические части: **Core** (расчёты) и **UI** (интерфейс).

## Структура папок

```
project/
├── Core/               # Model — расчёты
│   ├── TrajectoryCalculator
│   └── DataArray
├── ViewModel/          # Связка View и Model
│   ├── InputUpdateEvent
│   ├── OutputUpdateEvent
│   └── DataProvider
├── View/               # UI
│   ├── InputPanel       # ввод параметров
│   ├── Validation       # проверка данных
│   └── PlotArea         # график и отметки
├── README.md
└── .gitignore
```

> Названия файлов и папок уточняются по мере разработки; структура отражает логическое разделение слоёв.

## Правила работы с Git (кратко)

- Основная ветка — `main`, рабочая — `development`, черновые – `draft-core` и `draft-ui` соответсвенно.
- Коммиты осмысленные, в повелительном наклонении: `add validation for dt`, `fix vector scaling`.
- Перед merge в `development` — pull request и хотя бы один review.
- Не коммитить артефакты сборки и локальные настройки — используйте `.gitignore`.
